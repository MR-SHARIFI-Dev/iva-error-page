# Contributing to IVA EROR PAGE

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Keep the project dependency-free and preserve the single-file architecture.
3. Keep Persian and English experiences equivalent.
4. Test downloads, RTL layout and responsive behavior.
5. Open a pull request with a clear explanation and screenshots when visual behavior changes.

Use the exact project name **IVA EROR PAGE** in project-facing copy.
