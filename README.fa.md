آیوا ارور پیج یک آزمایشگاه دو‌زبانه و مجموعه‌ی متن‌باز برای ساخت صفحات خطای هاست و سرور است. وضعیت موردنظر را انتخاب کنید، پیش‌نمایش زنده را ببینید و فایل HTML مستقل آن را دانلود کنید. CSS و JavaScript داخل همان فایل قرار دارند و هیچ وابستگی خارجی وجود ندارد.

## قالب‌های موجود

- خطاهای 400، 401، 403، 404، 408 و 429
- خطاهای سرور 500، 502، 503 و 504
- صفحه‌ی قطع اینترنت
- صفحه‌ی تعمیرات و بروزرسانی

## امکانات

- رابط فارسی و انگلیسی کاملاً جدا
- چیدمان واقعی راست‌چین و چپ‌چین
- پیش‌نمایش زنده و دانلود با یک کلیک
- کپی کامل HTML
- رنگ‌بندی متفاوت بر اساس نوع خطا
- افکت‌های تله‌متری، Glitch، Scanline و سیگنال
- سازگار با موبایل، تبلت و دسکتاپ
- بدون کتابخانه، API، ردیاب یا ابزار Build
- آماده‌ی انتشار روی GitHub Pages

## اجرا

فایل `index.html` را مستقیماً باز کنید یا دستور زیر را اجرا کنید:

```bash
python -m http.server 8080
```

## نصب روی cPanel

فایل خطای موردنظر را دانلود و داخل `public_html` آپلود کنید. سپس از مسیر **Advanced → Error Pages** آن را به کد خطا متصل کنید. روش `.htaccess` نیز قابل استفاده است:

```apache
ErrorDocument 404 /404.html
ErrorDocument 500 /500.html
ErrorDocument 503 /503.html
```

## نصب روی DirectAdmin

فایل خطا را داخل پوشه‌ی مربوط به دامنه قرار دهید. مسیر متداول:

```text
/domains/example.com/public_html/404.shtml
```

## نصب روی Nginx

```nginx
error_page 404 /404.html;
error_page 500 502 503 504 /500.html;
```

بعد از بررسی تنظیمات، سرویس Nginx را Reload کنید.

## انتشار روی GitHub Pages

در تنظیمات ریپو، قسمت **Pages → Source** را روی **GitHub Actions** قرار دهید و پروژه را روی شاخه‌ی `main` ارسال کنید.
